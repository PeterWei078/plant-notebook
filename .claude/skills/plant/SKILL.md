# /plant — 植物資料查詢整理

使用者會給一個或多個植物名稱，例如 `/plant 九芎`、`/plant 苦楝、樟樹、大花咸豐草`。替每一種植物查好資料，整理成 App 的 JSON 格式（見下方「輸出格式」）。

## 1. 解析輸入

- 名稱可用空白、`、`、`,` 或換行分隔，每個名稱各查一次。
- 若名稱是俗名，或可能對應多種植物（例如「桂花」「茉莉」「野薑花」），以台灣最常見的那一種為準，並在 `notes` 註明其他可能。真的無法判斷時，先問使用者。

## 2. 查詢（以台灣來源為主）

用 WebSearch 或 firecrawl 搜尋，並實際打開頁面閱讀，不要只看搜尋摘要。建議來源依優先順序：

1. **台灣生物多樣性網絡 TBN**（tbn.org.tw）：學名、科名、原生或外來、分布
2. **臺灣植物資訊整合查詢系統**（tai2.ntu.edu.tw）、**臺灣植物誌**：形態描述、花果期
3. **林業及自然保育署、林業試驗所**、各縣市或公園的植物解說頁
4. **iNaturalist**（台灣觀察紀錄可推估實際花果期）、**維基百科中文版**：別名、英文名、毒性等補充

規則：
- 學名至少要由兩個來源互相印證。使用目前接受的學名，不用異名。
- 花期與果期以**台灣**的情況為準。來源之間不一致時取聯集，並在 `notes` 註明。
- **不要編造**。查不到的欄位就省略或留空，不要用猜的。

## 3. 欄位整理規則

| 欄位 | 規則 |
|---|---|
| `name` | 台灣最通用的中文名（TBN 的中文名優先） |
| `scientificName` | 學名，不加命名者，例如 `Lagerstroemia subcostata` |
| `family` | 中文科名，例如 `千屈菜科` |
| `aliases` | 別名陣列，最多 5 個，例如 `["拘那花", "猴不爬"]` |
| `englishName` | 常用英文名 |
| `plantType` | **優先**從這些選一個：喬木、灌木、草本、藤本、蕨類、多肉、水生、竹類。都不適用時才用其他詞 |
| `environments` | **優先**從這些選 2–4 個：路旁、公園、庭園、林地、溪邊、海岸、田野、山坡、盆栽。選台灣日常最容易遇到它的地方 |
| `keyFeatures` | **剛好 3 個**，每個 30 字以內。要是**在現場用肉眼就能確認**、能和相似種**區分**的特徵（例如樹皮、葉序、葉形、花色與花形、果實）。避免「葉子綠色」這種沒有鑑別力的描述 |
| `floweringMonths` / `fruitingMonths` | 1–12 的整數陣列，例如 `[6,7,8]` |
| `cautions` | 毒性、會刺人、會引起過敏、外來入侵種等。沒有就留空字串 |
| `notes` | 2–4 句簡介：原生、特有或外來；在台灣的分布；最容易混淆的相似種與分辨方法 |
| `sources` | 2–4 筆**實際讀過**的頁面 `{ "title": "TBN", "url": "https://..." }` |
| `idStatus` | 固定填 `"tentative"`（暫定），由使用者自己核對後再改成「已確認」 |

## 4. 輸出格式

不論查一種還是多種，都使用同一個外層格式：

```json
{
  "format": "plant-notebook/ai",
  "version": 1,
  "plants": [
    {
      "name": "九芎",
      "scientificName": "Lagerstroemia subcostata",
      "family": "千屈菜科",
      "aliases": ["拘那花", "猴不爬"],
      "englishName": "Subcostate Crape Myrtle",
      "plantType": "喬木",
      "environments": ["山坡", "林地", "公園"],
      "keyFeatures": [
        "樹皮光滑呈黃褐色，會片狀剝落留下斑駁花紋",
        "葉近對生，橢圓形，近無柄",
        "夏季開白色小花，花瓣有皺褶，呈圓錐花序"
      ],
      "floweringMonths": [5, 6, 7, 8],
      "fruitingMonths": [8, 9, 10, 11],
      "cautions": "",
      "notes": "台灣原生落葉喬木，低中海拔常見，常用於邊坡水土保持。與紫薇同屬，紫薇花多為紫紅色且多為栽培。",
      "sources": [
        { "title": "TBN 台灣生物多樣性網絡", "url": "https://..." }
      ],
      "idStatus": "tentative"
    }
  ]
}
```

（上例只示範格式，實際內容一律以查到的資料為準。）

## 5. 交付給使用者

1. 用 Bash 建立 `lookups/` 資料夾（已列在 .gitignore 中），存檔：
   - 一種植物：`lookups/<YYYY-MM-DD>-<中文名>.json`
   - 多種植物：`lookups/<YYYY-MM-DD>-批次-<N>種.json`
2. 用 `pbcopy < 檔案路徑` 把 JSON 複製到 Mac 剪貼簿。若 iPhone 和 Mac 登入同一個 Apple ID，並開啟「接續互通」，就能直接在手機上貼上。
3. 在對話中精簡回報：
   - 每種植物一行摘要：名稱、學名、類型、花期
   - 查不到或有疑慮的欄位
   - 完整 JSON 放在一個 ```json 程式碼區塊中（方便手動複製）
   - 使用方式：
     - **一種**：App →「新增」→「✨ 貼上 AI 查詢結果」→ 貼上 → 套用 → 補拍照片 → 儲存
     - **多種**：把 JSON 檔傳到手機（AirDrop、iCloud 雲碟或 LINE 傳給自己）→ App「設定」→「選擇 JSON 檔匯入」。只會新增，同名植物會略過

## 注意

- App 的解析程式在 `src/utils/aiImport.ts`（`AiPlant` 介面）。修改這份 Skill 的輸出格式時，兩邊必須同步修改。
- 新出現的 `plantType` 或 `environments` 名稱，App 會自動加進使用者的選項清單，所以盡量沿用上面的預設選項，避免選項越來越雜。
