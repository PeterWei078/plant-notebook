# 拈花惹草 🌸🔍

自用的「花草樹木識別學習整理」PWA，以手機操作為主。看到不認識的植物就拍下來，整理它的辨識重點，再用「看圖猜植物」測驗熟悉度。

## 功能

- **植物圖鑑**：照片卡片網格，可搜尋（名稱、別名、學名、特徵），快捷篩選「本月開花」「本月結果」「收藏」，也能依類型、環境、辨識狀態、熟悉度篩選
- **欄位**
  - 照片：最多 3 張代表照片（可標註全株、葉、花、果…），其中一張當封面
  - 名稱：中文名稱、學名、科名、別名、英文名
  - 分類：植物類型（單選）、常見環境（複選），兩者都能自行增減
  - 辨識：辨識關鍵 ×3、花期與果期（月份複選）
  - 狀態：辨識狀態（待辨識／暫定／已確認）、熟悉度（未測驗／不熟悉／普通／熟悉）
  - 其他：辨識依據與來源連結（可連到 TBN、Notion 筆記等）、觀察紀錄（日期＋地點）、注意事項、個人筆記、收藏
- **看圖猜植物**：先看封面照片四選一，答錯就顯示所有照片再猜一次。熟悉度會依結果自動更新：第一次答對記為熟悉，第二次才答對記為普通，兩次都錯記為不熟悉
- **AI 查詢（`/plant`）**：在 Claude Code 輸入 `/plant 九芎`，自動查詢台灣資料來源並整理好各欄位
- **匯出／匯入 JSON**：備份檔含照片；匯入時可選合併或覆蓋

## AI 查詢的使用方式

在這個資料夾開啟 Claude Code：

- **查一種**：`/plant 九芎` → 複製產出的 JSON → App「新增」→「✨ 貼上 AI 查詢結果」→ 套用 → 補拍照片 → 儲存
- **查多種**：`/plant 苦楝、樟樹、大花咸豐草` → 把產生的 `lookups/*.json` 傳到手機 → App「設定」→「選擇 JSON 檔匯入」（只會新增，同名植物會略過）

AI 查到的資料一律標記為「暫定」，請自己核對後再改成「已確認」。

## 開發

```bash
npm install
npm run dev            # 用手機測試：npm run dev -- --host
npm run build
npm run preview
```

技術架構：React + TypeScript + Vite、Dexie.js（IndexedDB）、vite-plugin-pwa。細節請見 [CLAUDE.md](CLAUDE.md)。

## 資料與備份

所有資料（含照片）只存在這支手機的瀏覽器裡，不會上傳到任何伺服器。換手機、換瀏覽器或清除瀏覽器資料之前，請先到「設定」匯出 JSON 備份。
